# 测试项目看板（v4.8.1）

一个单文件的测试项目协同管理平台：纯前端 HTML，双击即可运行，无需安装任何依赖。

## 在线访问

https://yhw430.github.io/

## 功能概览

| 模块 | 说明 |
| --- | --- |
| 项目总览 | 多项目排期，一级分类=项目任务，二级=测试流程 |
| 测试流程 | 5 层结构：S1 公共前置 → S2 方案评审 🚦 → S3 环境准备 → S4 测试任务执行（同级节点：研发/迭代/验收/部门协助） → S5 报告归档；每层「准入→测试项→SOP→门禁→输出交接」五步式 |
| 设备库（S4 分类） | 设备类型（纯侦测/纯打击/侦打诱一体等）→ 具体设备 → 每种类型的测试项模板，全部可增删改查 |
| 测试项台账 | 全部测试项、负责人、状态、证据、阻塞原因 |
| 缺陷 / 版本轮次 / 追溯矩阵 / 甘特 | 缺陷闭环、轮次管理、指标全覆盖追溯 |
| 每日记录 / 周报 | 每日进展可编辑保存，自动汇总周报（可接 AI API） |
| 问题墙 | 问题与阻碍的提出、认领、闭环 |
| 组员进度 | 组长看全部明细；组员看他人「总览进度 + 问题阻碍 + 资源申请」 |
| 资源调度 | 资源类型自定义（无人机/蒲公英网关/远程平台/车辆/移动电源…），按日期+时段排期排档；**清单式申请**一次勾多种资源自动拆分排期，冲突时提示协商交叉测试 |
| 账户与权限 | 组长 / 组员两类身份，权限分级 |
| 数据保险箱 | 自动快照、一键回滚、JSON 备份导入导出 |

## 数据存储

数据保存在各自浏览器的本地存储（localStorage / IndexedDB）中，**不上传服务器、不跨设备同步**。
需要多人共享同一份实时数据时，可进一步接入云端数据库。

## 本地使用

下载 `index.html` 双击打开即可（也可用 Chrome / Edge 打开）。

## 技术

单文件 HTML（HTML + CSS + 原生 JS），无构建产物、无外部依赖、可离线运行。
